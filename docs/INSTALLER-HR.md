# Sila – instalacija na Windows

1. Raspakiraj preuzeti ZIP i pokreni **Sila-<verzija>-VST3-Setup-x64.exe**.
2. Windows može pitati za administratorsku dozvolu – potvrdi (plugin ide u zajedničku VST3 mapu).
3. Prihvati licencu i klikni **Install**.

Plugin se instalira u `C:\Program Files\Common Files\VST3\Sila.vst3`. Upute, licence i izvorni kod
idu u `C:\Program Files\Voyagersquare\Sila`.

Nakon instalacije u DAW-u pokreni ponovno skeniranje pluginova (rescan) ako se Sila ne pojavi.

**Nadogradnja:** samo pokreni noviji installer – prepisat će staru verziju. Ako si ranije ručno
kopirao `Sila.vst3`, installer ga zamjenjuje istom mapom.

**Uklanjanje:** *Postavke → Aplikacije → Sila → Deinstaliraj*.

Installer sadrži samo VST3 plugin (bez Standalone aplikacije). Nije digitalno potpisan, pa Windows
SmartScreen može prikazati upozorenje: klikni *Više informacija → Ipak pokreni*.
